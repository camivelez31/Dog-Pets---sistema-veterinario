# Sistema de Gestión Veterinaria

Proyecto desarrollado en Flask para gestionar clientes, mascotas, citas, historias clínicas, facturación, guardería y auditoría.

## Tecnologías
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Cómo ejecutar
1. Clonar el repositorio
2. Instalar Flask:
   pip install flask
3. Ejecutar:
   python app.py
4. Abrir en navegador:
   http://127.0.0.1:5000
