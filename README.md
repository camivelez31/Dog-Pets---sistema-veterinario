# 🐾 DOG PETS - Sistema de Gestión Veterinaria

## Descripción

DOG PETS es un sistema web desarrollado en Flask para la gestión de una clínica veterinaria.

Permite administrar:

- Clientes
- Mascotas
- Citas
- Historias clínicas
- Guardería
- Facturación
- Pagos
- Auditoría

---

## Tecnologías utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- ReportLab

---

## Patrones de diseño implementados

- Singleton
- Factory
- Strategy
- Observer
- Decorator

---

## Instalación

Clonar repositorio:
git clone https://github.com/camivelez31/Dog-Pets---sistema-veterinario.git


Entrar a la carpeta:
cd Dog-Pets---sistema-veterinario


Instalar dependencias:
pip install flask
pip install reportlab


Ejecutar proyecto:
python app.py


Abrir en navegador:
http://127.0.0.1:5000
