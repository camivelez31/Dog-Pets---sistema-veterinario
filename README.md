# 🐾 DOG PETS - Sistema de Gestión Veterinaria

## Descripción

DOG PETS es un sistema web desarrollado en Flask para la gestión de una clínica veterinaria.

Permite administrar:

- Clientes
- Mascotas
- Citas
- Historias clínicas
- Guardería
- Facturación
- Pagos
- Auditoría

## Tecnologías utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- ReportLab

## Patrones de diseño implementados

- Singleton
- Factory
- Strategy
- Observer
- Decorator

## Instalación

```bash
git clone https://github.com/camivelez31/Dog-Pets---sistema-veterinario.git
cd Dog-Pets---sistema-veterinario
pip install flask
pip install reportlab
python app.py
```

Abrir en:

```text
http://127.0.0.1:5000
```
